Como conectar a OpenAI API para imagens
  1. Entre na plataforma da OpenAI, selecione ou crie um projeto para o escritório e gere uma chave de API do projeto.
  2. Confira saldo e faturamento da API na mesma organização. Se aparecer o benefício de créditos do ChatGPT Pro, você pode ativá-lo. Alguns projetos precisam verificar a organização para usar o modelo de imagem. Como ativar créditos elegíveis
  3. Cole a chave no campo OpenAI API abaixo. Na seção Arte da Luma, escolha a geração pela OpenAI, confirme a cobrança e salve.

Você pode manter Plano ChatGPT como provedor de texto. A opção de montagem com a marca cria um JPEG usando o texto da Luma, sem cobrança da API de imagens.
